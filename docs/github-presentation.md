# MarketMind portfolio copy

## GitHub repository description

Java Swing desktop application that uses JADE agents to coordinate market research, competitor discovery, risk review, budget analysis, and strategy. Exports source-aware briefs to PDF and Markdown.

## GitHub topics

`java`, `java-swing`, `jade`, `multi-agent-systems`, `market-research`, `ollama`, `searxng`, `pdfbox`

## LinkedIn project description

Built MarketMind, a Java desktop application for early-stage market research. A JADE manager delegates research, competitor discovery, risk review, and budget analysis to specialist agents, then coordinates strategy and report generation. The Swing workspace tracks agent activity and presents a strategy preview, with full reports saved as PDF and Markdown. The application combines World Bank indicators with optional SearXNG search and local Ollama inference. It also supports a local competitor CSV and a rule-based strategy fallback.

## CV project description

Built a Java Swing market research tool using eight JADE agents and ACL messaging to coordinate research, risk and budget analysis, strategy, and PDF and Markdown reporting.
